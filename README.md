## 📋 Descripción

Este repositorio contiene la página de mantenimiento que se muestra temporalmente mientras el sitio principal está siendo actualizado, mejorado o reparado. La página informa a los visitantes sobre el estado actual y la disponibilidad estimada del sitio.

## ✨ Características

- 🎨 Diseño limpio y responsive
- ⏳ Contador de tiempo regresivo *(opcional)*
- 📬 Formulario de notificación por correo *(opcional)*
- 📱 Compatible con dispositivos móviles
- ⚡ Carga ultrarrápida (sin dependencias pesadas)
